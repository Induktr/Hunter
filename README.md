Добро пожаловать в репозиторий Hunter. Это автономная система поиска работы, работающая в режиме 24/7.
В мире фриланса и найма побеждает тот, кто реагирует **быстро** и **релевантно**.

**Миссия системы:** Устранить "информационный шум" и рутину поиска, предоставляя оператору (тебе) только целевые вакансии с уже готовыми, психологически выверенными откликами по методологии TSD v27.2.2 и Крисса Восса.
